Ajustes de conexión

¿No tienes modelos? Escribe el nombre de uno de la biblioteca de Ollama y pulsa descargar. El tamaño depende del modelo y puede ocupar varios GB.

Necesitas Ollama instalado y encendido. Puedes obtenerlo en ollama.com/download y volver a comprobar la conexión.

«Probar y usar» envía solo un mensaje breve de prueba al modelo elegido; una API de pago puede cobrarlo. No envía tus recuerdos durante esta prueba.

Puedes cerrar esta ventana y configurar más tarde desde el menú de Núcleo. Las skills se configuran por separado en Ajustes y están apagadas en una instalación nueva.
